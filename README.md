# 🎮 Hangman Game (Python)

## 📌 Project Overview
This project is a simple text-based Hangman game built using Python. The player guesses a hidden word one letter at a time. Each incorrect guess reduces the remaining attempts, and the game ends when the player either guesses the word or runs out of chances.

---

## 🚀 Features
- Random word selection from a predefined list  
- Maximum of 6 incorrect guesses  
- Displays correctly guessed letters  
- Prevents repeated guesses  
- User-friendly console interaction  
- Beginner-friendly logic
